# シミュレーションの公開

GitHubは新規独立リポジトリのみ作成・pushする。元リポジトリの履歴やPRは参照・変更しない。公開前にファイル一覧・資格情報パターン・作者・ハッシュ・シミュレーション注記を確認する。

Notion MCPの利用可能なツールにはSitesの公開操作が見当たらない。公開済みとは扱わない。親ページの「共有」→「公開」から公開し、子DBとレコードをログアウト状態で確認する。検索エンジンのインデックスは有効化しない。無関係なページは子として移動しない。公開先URLは実際に発行された値を記録する。


2026-10-25実施結果：GitHub Public作成とpush、NotionアプリのPublish操作を完了。[公開URL](https://airy-mantis-6f3.notion.site/Talklear-Development-Simulation-404bfd032199810eac93f56f7cf89f99)。Search engine indexing Off、未ログインChromeで閲覧確認。MCPに公開操作がないためアプリUIで補完した。
