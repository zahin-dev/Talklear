# 実装段階とコミットの対応

各段階の仕様・変更範囲・検証結果は[stage-map.json](stage-map.json)に記録します。タスク・開発セッションから対象コードと関連コミットを参照できます。

初期試作はDBなし・認証なし・localhost専用です。PostgreSQLへの切替時にAPIと安全策を統合し、画面は関連モジュールがそろった段階で統合しています。一括統合した変更は、個別タスクの差分と区別して記載します。

セッションの日付とGitコミット日時は各資料で管理します。レビューの対象範囲と、テストの実行結果はそれぞれの記録を参照してください。

取得版との照合では、PowerShell9ファイルの改行正規化を確認し、7a577e7で取得ZIPのCRLFバイトを保存しました。処理内容・依存・設定値は変更していません。元の.gitattributesは保持し、検証では作業ツリーとコミット内のバイト列を照合します。
