# 復元できた段階と限界

全コミットは現在の実行日時で作成。各段階の仕様・実行した検証・未実行の理由は[stage-map.json](stage-map.json)に記録する。

初期試作はDBなし・認証なし・localhost専用で、完成版とのAPI互換性を保証しない。PostgreSQLへの切替で試作APIを削除し、完成版APIと安全策を一括統合した。最終UIも関連モジュールが揃った時点で統合した。したがって、BUG資料のすべての旧設計や修正を独立コミットとして再現したわけではない。レビューは完成版の該当実装と実際の復元コミットを比較する学習用資料。セッション日とコミット順序の対応は概念的であり、実際の歴史の証明ではない。

最終照合で、Gitの属性によるPowerShell9ファイルの改行正規化を検出した。7a577e7で取得ZIPのCRLFバイトをGitオブジェクトへそのまま保存し直した。処理内容・依存・設定値は変更しない。ローカルの`.git/info/attributes`に`*.ps1 -text`を置き、最終ステージングで再び正規化されないようにした。追跡対象の元`.gitattributes`自体は変更していない。検証スクリプトは作業ツリーとコミット内のバイト列の両方を検査する。
