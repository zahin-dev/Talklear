# BUG-20260930-001 — 送信応答が新着カーソルを進める

日付：2026-09-30 | 担当：member2

## Classification

発生条件・原因・対策・回帰テストを整理する。現行実装との対応は対象コードを参照。

## 症状

cursor=12として11が飛ぶ想定

## 発生条件

他人の発言より先に自分の送信応答が届く

## 再現手順

cursor=10で他人11、自分12の送信応答を先に処理

## 期待結果

次回pollで11を取得する

## 確認観点

cursor=12として11が飛ぶ想定。

## 影響範囲

画面の新着取得

## 原因仮説

表示済IDと取得済IDの混同

## 調査過程

MessageFeedへ受信経路を分離する検討

## 原因

送信応答でafterを進める設計

## 対策案と現行実装

addとreceiveを分け、poll応答だけcursor更新、DOMはID位置へ挿入。

## 回帰テスト

message-feed.test.mjs 1・2件目。 本実行の結果はTests正本で管理。

## 対象コード

`src/main/resources/static/message-feed.js`
