# メンバーと工数（指定条件 / 計画値）

|役割名|主担当|経験・得意|苦手・支援|開発計画|
|---|---|---|---|---|
|member1|リーダー・バックエンド|比較的大規模な個人開発1件、Java・API・SQL・切分け|UI・UXはmember2に相談|70時間|
|member2|フロントエンド|小規模な個人開発1件、HTML/CSS/JS・操作改善|DB・運用は他2名と確認|70時間|
|zahin-dev|基盤・QA|小規模な個人開発1件、Docker・再現・テスト|大規模設計・非同期は共同レビュー|70時間|

全員3年生・友人。匿名役割であり、実在人物の発言引用ではない。14回×各5時間。各回15人時をタスク数で割った配分値は、担当個人の実測時間ではなく、支援・会議・レビューを含むチーム枠。KPTは各人3.5時間を別計上する。

各セッションの担当はDevelopment Sessions参照。設計時は3名共同、実装時も担当がない人を休みにせず、仕様確認・再現・レビューへ参加する。
