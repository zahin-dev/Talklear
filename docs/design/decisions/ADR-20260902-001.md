# ADR-20260902-001 — Javaと素のJavaScriptを採用

工程モデル | 工程日：2026-09-02 | 担当：全員

## Context

3人全員で設計案を比較した検討例。現在の採用構成との対応を確認する。

## Problem

Javaと素のJavaScriptを採用を、限られた作業枠で選ぶ。

## Options

Java/Spring Boot + HTML/CSS/JS／Python/FastAPI、React

## Trade-offs

member1のJava経験を活かし、member2が画面を直接調整できる。FastAPIは未実装の比較案。Reactもコード移行の履歴はない。

## Decision

Java/Spring Boot + HTML/CSS/JS

## Reason

member1のJava経験を活かし、member2が画面を直接調整できる。FastAPIは未実装の比較案。Reactもコード移行の履歴はない。

## Consequences

ビルド系統を増やさず、静的画面とAPIを同じアプリから配信する。UI拡大時の状態管理は手作業になる。

## Risks

ビルド系統を増やさず、静的画面とAPIを同じアプリから配信する。UI拡大時の状態管理は手作業になる。
