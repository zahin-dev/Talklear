## Context

3人全員で設計案を比較した再現例。現在の採用構成との対応を確認する。

## Problem

Javaと素のJavaScriptを採用を、限られた作業枠で選ぶ。

## Options

Java/Spring Boot + HTML/CSS/JS／Python/FastAPI、React

## Trade-offs

member1のJava経験を活かし、member2が画面を直接調整できる。FastAPIは未実装の比較案。Reactもコード移行の履歴はない。

## Decision

## Reason

member1のJava経験を活かし、member2が画面を直接調整できる。FastAPIは未実装の比較案。Reactもコード移行の履歴はない。
