# ADR-20260909-001 — 招待コードと参加トークン

日付：2026-09-09 | 担当：全員

## Context

3名で比較する設計案と、採用構成との対応を整理する。

## Problem

招待コードと参加トークンを、限られた作業枠で選ぶ。

## Options

12文字招待コード + ランダム参加トークン／表示名だけ、アカウント登録

## Trade-offs

登録なしの雑談を優先する一方、表示名を認証情報には使わない。トークンはSHA-256で保存する。

## Decision

12文字招待コード + ランダム参加トークン

## Reason

登録なしの雑談を優先する一方、表示名を認証情報には使わない。トークンはSHA-256で保存する。

## Consequences

招待コードを知る人は履歴にアクセス可能。本人確認・招待失効・期限は未実装。

## Risks

招待コードを知る人は履歴にアクセス可能。本人確認・招待失効・期限は未実装。
