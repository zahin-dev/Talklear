# ADR-20260922-001 — 日英の端末内翻訳と原文継続

工程モデル | 工程日：2026-09-22 | 担当：全員

## Context

3人全員で設計案を比較した検討例。現在の採用構成との対応を確認する。

## Problem

日英の端末内翻訳と原文継続を、限られた作業枠で選ぶ。

## Options

Chrome Translator / LanguageDetector、原文フォールバック／外部翻訳API、翻訳必須の入室条件

## Trade-offs

APIキーと翻訳サーバーを不要にする。対象はPC Chromeに絞り、準備失敗で会話を止めない。

## Decision

Chrome Translator / LanguageDetector、原文フォールバック

## Reason

APIキーと翻訳サーバーを不要にする。対象はPC Chromeに絞り、準備失敗で会話を止めない。

## Consequences

スマホと非対応環境は原文。訳文品質・混在短文の判定は別途評価が必要。

## Risks

スマホと非対応環境は原文。訳文品質・混在短文の判定は別途評価が必要。
