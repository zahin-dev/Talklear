# ADR-20261013-001 — コンテナ共用とクラウド設定

工程モデル | 工程日：2026-10-13 | 担当：全員

## Context

3人全員で設計案を比較した検討例。現在の採用構成との対応を確認する。

## Problem

コンテナ共用とクラウド設定を、限られた作業枠で選ぶ。

## Options

Dockerfile共用 + Vercel設定 + Neon PG*／PCのローカルDBを公開、環境ごとに別コード

## Trade-offs

秘密を環境変数に分離し、PG*とCHAT_DB_*の互換性を確保する。verify-fullでTLSを検証する。

## Decision

Dockerfile共用 + Vercel設定 + Neon PG*

## Reason

秘密を環境変数に分離し、PG*とCHAT_DB_*の互換性を確保する。verify-fullでTLSを検証する。

## Consequences

Free枠の容量・継続運用・公開URLは確認事項。設定ファイルの存在はデプロイ成功の証拠ではない。

## Risks

Free枠の容量・継続運用・公開URLは確認事項。設定ファイルの存在はデプロイ成功の証拠ではない。
