# ADR-20260902-002 — 原文をPostgreSQLへ保存

日付：2026-09-02 | 担当：全員

## Context

3名で比較する設計案と、採用構成との対応を整理する。

## Problem

原文をPostgreSQLへ保存を、限られた作業枠で選ぶ。

## Options

Spring JDBC + PostgreSQL／メモリのみ、ファイル保存

## Trade-offs

再入室と履歴保持の要件を満たし、SQLと一意制約を直接確認できる。初期試作のみメモリで契約を試す。

## Decision

Spring JDBC + PostgreSQL

## Reason

再入室と履歴保持の要件を満たし、SQLと一意制約を直接確認できる。初期試作のみメモリで契約を試す。

## Consequences

3表の参照整合性を使う。接続設定・DB運用の学習負担が増える。

## Risks

3表の参照整合性を使う。接続設定・DB運用の学習負担が増える。
