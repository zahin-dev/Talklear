# ADR-20260915-001 — 2秒ポーリングと原文交換

工程モデル | 工程日：2026-09-15 | 担当：全員

## Context

3人全員で設計案を比較した検討例。現在の採用構成との対応を確認する。

## Problem

2秒ポーリングと原文交換を、限られた作業枠で選ぶ。

## Options

HTTP state API + after / before／WebSocket、全履歴の毎回取得

## Trade-offs

初チーム開発で双方向接続の管理を増やさず、差分取得を理解する。ページングは次回に具体化。

## Decision

## Reason
